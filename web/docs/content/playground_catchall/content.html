Catch-all routing

This page is registered at /catchall/*rest. Everything after /catchall/ — one segment or twenty — is captured into the single binding rest, joined with slashes. Same machinery as the param playground, different trie node type.

How it differs from :param

  • Greedy. :section captures exactly one URL segment. *rest captures one OR more.
  • Terminal. A *name must be the last thing in the pattern. You can have /files/:id/preview but not /files/*path/preview.
  • One per pattern. Each path can have at most one catch-all, and it must be at the end.

What this is good for

  • Proxy-style routes that forward a sub-path to a backend.
  • Static file serving from a single content tree (/static/*path → dist/static/path).
  • API versioning fallthrough (/api/v1/*rest → one handler interprets the rest).
  • Any URL space whose depth is unknown at compile time.
