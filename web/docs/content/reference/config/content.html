config.toml

A single file at web/config.toml describes the server, the directory layout, and the list of sites. The build and the runtime read it. Nothing else does.

Server

KeyTypeNotes
portintListen port. Override at runtime via PORT=8083 ./main.
hoststringBind interface. 0.0.0.0 for all.
read_timeoutdurationPer-connection read deadline. Strings like "15s".
write_timeoutdurationPer-connection write deadline.
idle_timeoutdurationKeep-alive idle timeout.

Directories

KeyDefaultNotes
web"web"Project content root.
content"content"Per-site subdir for pages.
static"static"Per-site subdir for static assets.
templates"templates"Per-site subdir for layouts and partials.
dist"dist"Output for ActionFile-served files. Per-site sub-directory.
meta"meta"Where manifests, caches, and the SQLite DB live.

Each site lives at <web>/<site.Name>/{content,static,templates}. Path conventions are uniform; only the site name changes.

Sites

Each [[site]] block declares one site. The build emits a manifest per site at meta/<name>_router.bin; the runtime registers each host in a Host→manifest map. 

[[site]]
name = "main"
hosts = ["*"]      # * = default fallback

[[site]]
name = "docs"
hosts = ["docs.localhost"]
KeyTypeNotes
namestringDirectory name under web/. Used as manifest filename prefix.
hosts[]stringHost headers that route to this site. "*" marks the fallback.

Multiple hosts per site

A site can listen on several hostnames — useful when alias and canonical hostnames both need to work. 

[[site]]
name = "docs"
hosts = ["docs.example.com", "docs.localhost"]

The default fallback

The first site listing "*" in its hosts is used when no host matches. If no site claims "*", the first site in the file becomes the default.

Cache

Used by future request-cache features; currently informational.

KeyTypeNotes
max_sizeintMax in-memory entries.
default_expirationdurationDefault TTL for cached responses.

Build

KeyTypeNotes
ignore_filestringFilename for per-directory ignore patterns. Default .buildignore.

Full example

[server]
port = 8082
host = "0.0.0.0"
read_timeout  = "15s"
write_timeout = "15s"
idle_timeout  = "60s"

[directories]
web = "web"
content = "content"
static = "static"
dist = "dist"
meta = "meta"
templates = "templates"

[[site]]
name = "main"
hosts = ["*"]

[[site]]
name = "docs"
hosts = ["docs.localhost"]
